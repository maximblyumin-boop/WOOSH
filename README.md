# Тестовая сборка «СНИКЕР ТЕХ»

Файл `sneaker-tech-publish.zip` — готовая статическая сборка сайта для тестового размещения.

1. Скачайте ZIP и распакуйте.
2. В корне распакованной папки находится index.html.
3. Загрузите эту папку через Netlify Drop: https://app.netlify.com/drop

Внутри: 10 русскоязычных страниц, анимированное изображение аппарата, калькулятор и демонстрационные формы без отправки персональных данных. Серверные интеграции не подключены.

Это ветка для передачи сборки; основная ветка проекта не изменяется.
